# Asset provenance

All assets shipped in this repository were generated specifically for AETHRA: Wildbound during this build.

- `assets/icon.svg`: original vector mark generated for this project.
- `assets/audio/*.wav`: generated synthetic audio tone assets for UI, footsteps, digging, placement, jump and creature ambience.
- 3D player/creature visuals are generated procedurally in Godot code and do not use third-party models.

No Minecraft/Mojang/Microsoft copyrighted texture, model, sound, logo, character, or proprietary code is included.
